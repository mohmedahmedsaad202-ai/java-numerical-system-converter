# Java Numerical System Converter

A Command-Line Interface (CLI) application written in Java that performs conversions between fundamental numerical bases: Decimal, Binary, Hexadecimal, and Octal.

## Features
- **Multi-Base Conversions:** Supports Decimal-to-All, Binary-to-Decimal, and Hexadecimal-to-Decimal conversions.
- **Robust Exception Handling:** Catches number format errors and invalid inputs gracefully.
- **Clean CLI Architecture:** Modular methods designed for easy extension.

## Tech Stack
- **Language:** Java (JDK 8 or higher)
- **Tooling:** Command-Line Execution / Native Java APIs

## How to Compile & Run
```bash
javac Converter.java
java Converter
